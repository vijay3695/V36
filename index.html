PROJECT RULES

About V36

Evidence, not verdicts

V36 surfaces dates and observable activity. It does not label projects dead or calculate an overall health score. Older repositories remain visible unless you choose a commit-age filter. Missing information is marked unknown or unavailable, never treated as zero.

Data and rate limits

Search and repository information come from the public GitHub API. Unauthenticated API limits apply. V36 stops additional requests when limited, preserves loaded results, and offers manual retry. Filters that need extra metadata can only evaluate the loaded set.

Category inference

Categories are inferred conservatively from issue text and labels. Official labels remain separate from inferred categories; inference is not a GitHub-provided fact.

AI context packs

Context packs are plain text for use in an AI assistant you choose. They contain only information V36 actually retrieved, with links, fetch times, and missing context disclosed. V36 does not call an AI API, execute repository code, run tests on a repository, or create pull requests.

Privacy and limitations

Saved items stay in this browser's local storage. Do not save credentials or tokens. Shareable URLs contain search settings, not saved private data. GitHub content and imported files are untrusted and must never be executed.

V36 is in development. Do not consider a release verified until tests, CI, accessibility checks, manual acceptance, and known limitations have been reviewed.
