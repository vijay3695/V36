# V36 v0.1.0 — Public Preview

V36 is a free, static-first tool for discovering public GitHub issues, reviewing activity evidence, saving issue/search references locally, and generating portable source-backed context packs for the AI assistant chosen by the user.

## Included

- Discover issues with language, label, issue type, date, activity-age, star-count, contribution-category, and sorting filters.
- Issue detail views with source links, activity evidence, and explicit unavailable/unknown states.
- Browser-local saved issues and searches, validated import/export, duplicate handling, and shareable filter URLs.
- Copyable context packs that disclose their sources, fetch times, missing context, and limitations.
- Light/dark themes, keyboard focus, reduced-motion support, responsive layouts, and explicit loading/error/rate-limit states.
- MIT license and static GitHub Pages hosting; no account, backend, GitHub token, or paid AI API is required.

## Release verification

The Publish v0.1.0 GitHub Actions workflow checks out the exact triggering commit, installs dependencies and Playwright Chromium, runs `npm run test:all`, and creates this public release only if the complete suite passes. The workflow run is the authoritative pass/fail record for this exact release commit.

Numeric light/dark theme contrast ratios for text, controls, borders, focus, status indicators, inferred tags, and disabled controls are documented in `docs/CONTRAST_AUDIT.md` and recomputed by `tests/contrast-audit.test.js`.

## Known limitations

- GitHub unauthenticated API rate limits apply; results can be partial and metadata can be unavailable.
- Metadata filters only evaluate loaded results; the interface does not scan every matching issue.
- Similar issues and pull requests are surfaced through GitHub search links; automatic duplicate detection is not included.
- Context packs do not execute repository code, run target-project tests, call an AI API, or make code changes.
- Saved data stays in this browser and can be lost if browser storage is cleared.
